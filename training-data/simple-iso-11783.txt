ISO known as Tractors and machinery for agriculture and forestry Serial control and communications data network commonly referred to as ISOBUS is a communication protocol for the agriculture industry based on and harmonized with the SAE J protocol which is based on the CAN bus . Official maintenance of ISO is done by ISO TC SC WG and WG however the Agricultural Industry Electronics Foundation AEF helps guide the ongoing direction of ISOBUS organizes PlugFest events where many companies meet to test together and provides formal ISOBUS conformance test tools. The ISOBUS standard specifies a CAN network for control and communications on forestry or agricultural tractors and implements although most usage is in the agricultural domain. It was noted as a widely used industry standard in . The standard comes in parts ISO General standard for mobile data communication ISO Physical layer ISO Data link layer ISO Network layer ISO Network management supporting plug and play changes to the network ISO Virtual terminal a universal human machine interface for implement ECUs ISO Implement messages application layer communication of signals speeds temperature work state etc. ISO Power train messages ISO Tractor ECU a gateway between the open ISOBUS and the tractor private network and power management for both a A and a A circuit. ISO Task controller and management information system data interchange prescription application and data logging of implement operation. ISO Mobile data element dictionary types of information being commanded and data logged e.g. seeds per acre ISO Diagnostics services identification of devices and functionalities within those devices ISO File server a network accessible location for storage and retrieval of data ISO Sequence control the record edit and playback of commanded sequences to offload the operator from as many repetitive tasks. The Agricultural Industry Electronics Foundation works to promote ISOBUS and coordinate enhanced certification tests for the ISO standard.
