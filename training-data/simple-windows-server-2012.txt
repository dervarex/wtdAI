Windows Server codenamed Windows Server is the sixth release of Windows Server. It is the server version of Windows and succeeds Windows Server R . Two pre release versions a developer preview and a beta version were released during development. The software was generally available to customers starting on September . It mainstream support ended on October and extended support ended on October . Windows Server is eligible for the paid Extended Security Updates ESU program free for Azure Virtual Desktop users . It allows to purchase Security Updates for years in early installments. Security Updates are available for the operating system until October . Unlike its predecessor Windows Server has no support for Itanium based computers and has four editions. Various features were added or improved over Windows Server R with many placing an emphasis on cloud computing such as an updated version of Hyper V an IP address management role a new version of Windows Task Manager and ReFS a new file system. Windows Server received generally good reviews in spite of having included the same controversial Metro based user interface seen in Windows . The successor to Windows Server called Windows Server R was released along with Windows . in October . A service pack formally designated Windows Server R Update was released in April . Windows Server codenamed Windows Server is the fifth release of Windows Server family of operating systems developed concurrently with Windows . It was not until April that the company announced that the final product name would be Windows Server . Microsoft introduced Windows Server and its developer preview in the BUILD conference on September . However unlike Windows the developer preview of Windows Server was only made available to MSDN subscribers. It included a graphical user interface GUI based on Metro design language and a new Server Manager a graphical application used for server management. On February Microsoft released an update for developer preview build that extended its expiry date from April to January . Before Windows Server was finalized two test builds were made public. A public beta version of Windows Server was released along with the Windows Consumer Preview on February . The release candidate of Windows Server was released on May along with the Windows Release Preview. The product was released to manufacturing on August and became generally available on September . However not all editions of Windows Server were released at the same time. Windows Server Essentials was released to manufacturing on October and was made generally available on November . As of September all students subscribed to DreamSpark program can download Windows Server Standard or Datacenter free of charge.
