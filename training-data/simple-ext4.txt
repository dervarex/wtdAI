ext fourth extended filesystem is a journaling file system for Linux developed as the successor to ext . ext was initially a series of backward compatible extensions to ext many of them originally developed by Cluster File Systems for the Lustre file system between and meant to extend storage limits and add other performance improvements. However other Linux kernel developers opposed accepting extensions to ext for stability reasons and proposed to fork the source code of ext rename it as ext and perform all the development there without affecting existing ext users. This proposal was accepted and on June Theodore Ts'o the ext maintainer announced the new plan of development for ext . A preliminary development version of ext was included in version . . of the Linux kernel. On October the patches that mark ext as stable code were merged in the Linux . . source code repositories denoting the end of the development phase and recommending ext adoption. Kernel . . containing the ext filesystem was finally released on December . On January Google announced that it would upgrade its storage infrastructure from ext to ext . ext fourth extended filesystem is a journaling file system for Linux. ext is the default filesystem for many distributions such as Debian and Ubuntu. It is made to use as much of the space available as possible.
