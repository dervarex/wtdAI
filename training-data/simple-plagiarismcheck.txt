It provides several tools for text analysis including originality checking software an AI generated text detector called TraceGPT grammar checking functionality and fingerprint authorship verification. Tools also include browser extensions such as a TraceGPT Chrome extension. PlagiarismCheck.org supports API integration with learning management systems LMS such as Canvas Moodle Brightspace Populi Schoology and Google Classroom. After analysis the system creates a report showing the similarity score a percentage of the match with external sources the tool finds while scanning highlighted potentially problematic parts of the text and the links to the sources where matching content has been detected.
