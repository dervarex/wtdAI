Microsoft Office is a previous version of Microsoft Office now replaced by Microsoft Office . It included Microsoft Office Web Apps an online version of Microsoft Office. The software was officially released to the public on June . Mainstream support of Office ended on October extended support ended on October . The Microsoft Office Web Apps was introduced as a new feature of Microsoft Office. It allows users to share documents easily with one another. Many people can edit the document and also download to edit on their version of Microsoft Office . However users need to have a Windows Live ID and the storage space is only limited to GB. Office Web Apps can only create types of documents Microsoft Word documents Microsoft Excel documents Microsoft Powerpoint documents Microsoft OneNote documents Other types of documents like Microsoft Publisher can only be created using a paid version of the software.
