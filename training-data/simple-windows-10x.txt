Windows X is a cancelled version of Windows . It was announced by Microsoft on October . It was originally made as an OS that would support devices with dual screens. X was planned to be released in . But in May Microsoft announced the cancellation of Windows X. However some changes made were put into the newer Windows . The focus of Windows X was changed from dual screen devices to single screen devices in because of the higher demand for regular computers during the COVID pandemic. The taskbar is now in the middle and has three sizes small made for desktop computers. The medium and large sizes were made for touch computers. The Start menu is now fullscreen making it more easier to use on touchscreen devices. It no longer supports Win apps. But you still can run Win apps by enabling it in Settings. It has a cloud based Explorer that now uses OneDrive. Its now called Files instead of File Explorer or Windows Explorer for older Windows versions.
