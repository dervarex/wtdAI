In computing chr is a type of file format commonly used for graphics i.e. D Max Characters and Homebrew NES Dev Graphics and character sets. chr files are used to draw x tiles for homebrew NES development. To draw graphics for the NES such as backgrounds or sprites they must be pieced together using x pixel tiles constrained to colors. The contents of a chr file can be summed up as multiple lines of bit strings. For example take the first line of the chr file for the game Super Mario Bros.
