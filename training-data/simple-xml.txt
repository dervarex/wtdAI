The Extensible Markup Language XML for short is a markup language like HTML but built to be extensible and was created by the World Wide Web Consortium W C . XML defines rules for the construction of a document. XML adds context to the information in a document. It does not say how this should be displayed. Some programs get information out of an XML document. To do that they need an API. There are many APIs for XML. JSON was built to replace this purpose of XML. You can write a description of an XML document in a way that is useful for programmers. There are several languages for this the best known is called DTD. XML uses less than to show tags. For example a paragraph in HTML would be lt p gt . A closing tag is a tag used to enclose the value of the tag. The tag has a slash before its name. For example lt p gt A tag which is empty can be represented as an opening tag but with a slash before the gt . For example lt p gt or lt p gt The XML specification defines a valid XML document as a well formed XML document which also conforms to the rules of a Document Type Definition DTD .
