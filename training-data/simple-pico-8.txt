PICO is a fantasy video game console and game engine made by Lexaloffle Games. It is styled after bit hardware from the s. Code in Lua music sound effects sprites and maps can be made in PICO directly. Games can be exported to cartridges P for text based or P .PNG for a PNG image HTML an HTML file or to Lexaloffle's official BBS bulletin board system which can be found on a web browser or in PICO using its splore mode or as of v . . a Windows macOS Linux or Raspberry Pi program. PICO was also made available for CHIP computers. PICO 's successor is Picotron. It is a fantasy workstation with less limitations. The first version an alpha version was released on March . The original version of Celeste later Celeste Classic was made for PICO in four days for a game jam. It became so popular that an enhanced version was released in . The enhanced version includes the original as an Easter egg. PICO always uses a pixel screen with colors and four audio channels. Two color palettes are available the last can be used by making the color ID bigger than . No hardware is emulated. This allows it to do more things. PICO was created by Joseph White best known as Zep. It started as LEX . Development stopped for some time until after he started working on Voxatron another game engine. It was going to use BASIC specifically a dialect similar to BBC BASIC which was later replaced with Lua because it was easier to use and could do more things. He added some built in tools and renamed it to PICO . The color palette was inspired by the Commodore and the channel audio by the Amiga . Inspiration was also taken from the Apple IIe Famicom and other platforms. He created the term fantasy console to describe it and other platforms with intentional limitations.
