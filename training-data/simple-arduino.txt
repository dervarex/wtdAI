Arduino is a small popular microcontroller that makes it very easy for people to make electronic things. It has two parts a circuit board and a program that lets people tell the circuit board what to do. As of more than Million Arduino's had been sold. The machine part is open source which means that anybody can make their own version of an Arduino machine for free. An official Arduino costs around US . The original Arduino is made by a company in Italy called Smart Projects but other types of Arduino boards have been designed by SparkFun Electronics an American company. Sometimes people will make other machines that go on top of an Arduino board and let the board do more things. These are called Arduino shields . They can do different things like let an Arduino machine connect to the internet or add a touchscreen or let an Arduino use GPS to figure out where it is. Shields can also combine and stack on top of each other. Arduino's are programmed in C or C using a program also called Arduino. An example program to blink a light LED could look like this void setup pinMode LED PIN OUTPUT Enable pin for digital output void loop digitalWrite LED PIN HIGH Turn on the LED delay Wait one second milliseconds digitalWrite LED PIN LOW Turn off the LED delay Wait one second First the code after void setup runs. This tells the Arduino that pin is going to be sending data out. Most Arduino boards have an LED attached to pin . Then the code after the void loop runs. When it reaches the bottom the code after the void loop runs again until the Arduino is turned off. This code makes the Arduino tell the LED to turn on wait a second then turn off and wait another second. Since it repeats this code will turn the LED on and off again and again.
