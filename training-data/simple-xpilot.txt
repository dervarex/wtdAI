XPilot is multiplayer D space action video game. It is an open source game and its first version was released in . XPilot was created in by Bj rn Stabell and Ken Ronny Schouten students in computer science at the Troms university Norway as a multiplayer game similar to Thrust. They received a lot of patches and feedback when they released the first public version. The game has been improved a lot by players from all the world and has many contributors. Originally only available on UNIX it was ported on the Mac OS and Microsoft Windows. It has been forked and new versions appeared XPilot and XPilot NG Next Generation . In a version was released for iPhone and iTouch. Several projects are currently in progress a Java version of XPilot an optimised version for the Blood's Music map and a project to improve the artificial intelligence.
