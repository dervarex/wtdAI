ASCII is binary code used by electronic equipment to handle text using the English alphabet numbers and other common symbols. ASCII is an abbreviation for American Standard Code for Information Interchange. ASCII was developed in the s and was based on earlier codes used by telegraph systems. The code includes definitions for characters which are assigned numbers from to . Numbers to stand for letters numbers and symbols such as abc ABC and . Numbers to and the number stand for characters that control how text is processed and are not printed. ASCII uses binary digits bits to represent characters. The bits in normal base numbers represent the upper case letter A represents B represents C and so on. Programmers often use hexadecimal base numbers and you can look that up in the Hex column. An ASCII computer file uses one byte for each character. A byte has bits so can hold an ASCII character with one bit spare. In the past the spare bit was sometimes used as a parity bit to help check if the data had been corrupted. ASCII has no formatting control for bold or Italics etc. Sometimes someone talks about a file or document in ASCII meaning it is in plain text. Standard ASCII is still commonly used particularly in computer software and HTML files. Until it was the standard for URLs. Often a web site that has fields for entering text will only take ASCII text. Any special markups for bold or centered text etc. will show up incorrectly. ASCII does not have diacritics marks that are added to a letter like the dots umlauts above vowels in German or the tilde above the 'n' for the ' ' used in Spanish . It was only meant for English and doesn't work well for most other languages. Some English words borrowed from other languages use these marks as well like resum see Appendix English words with diacritics . This led to some systems using bit a full byte instead of bits. The proper name for systems that use bits is called extended ASCII. Eight bits allows for characters. The first characters must be the same as for ASCII and the rest are usually used for alphabetic letters with accents for example like and . This solves the problem for a few languages that are based on the Latin alphabet although not all extended ASCII systems are the same. Other alphabets like the Greek alphabet Cyrillic alphabet need a different set of characters. And some systems like those using Chinese characters still do not work as they use thousands of characters. So Unicode was created to have one common system for all languages.
