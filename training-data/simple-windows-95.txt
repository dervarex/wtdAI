Windows is an operating system created by Microsoft. Microsoft sent it to computer makers on July and stores began selling it on August . It was the first operating system in the Windows x family replacing Windows . . Although Windows is thought of as an operating system by itself it works on top of MS DOS. You can think of it as a visual version of MS DOS. This means Windows can run both MS DOS programs and Windows ones but programs made just for Windows will not work in MS DOS. Windows introduced a new graphical user interface GUI . It brought the Windows Explorer file manager file shortcuts on the desktop and a taskbar with a notification area and the Start menu. This was the first Windows operating system to use the Start menu. Since then the Start menu has been used in almost all Windows operating systems except for the tablet design Start screen in Windows . Windows also added many technical improvements. It introduced Plug and Play driver setup to help users add new hardware easily. It was Microsoft's first operating system to support long file names up to characters letters numbers or symbols plus the file extension. Before that file names could only be eight characters long. Before that file names could only be eight characters long plus a file extension. It was also the first Windows operating system with built in ways to connect to the Internet and the first to fully support CD ROMs though Windows .x could also access CD ROMs with MSCDEX . Microsoft spent a lot of money advertising Windows before its release. This created much excitement among buyers. Windows was a major success and is considered one of the most important products in personal computing history. Windows remained popular until three years later when Microsoft introduced Windows . Microsoft ended mainstream support for Windows on December and ended extended support on December . Planning for Windows started in March shortly before Microsoft released Windows . . At that time Windows for Workgroups . and Windows NT . were not yet released. Microsoft wanted to make two new operating systems. The first was a high end system for business users code named Cairo. The second was a simpler system for home users code named Chicago. Chicago was designed to replace Windows . by using new bit technology. Cairo was planned as Microsoft's next main system based on Windows NT featuring a new user interface and file system. However Microsoft never released Cairo. Instead parts of the Cairo project were used in Windows NT . in July . Its new file system was left out but it later became WinFS. When Windows . was released IBM started selling OS . . Microsoft realized it needed an updated version of Windows. This new system needed to support bit programs and run multiple tasks at the same time. It also needed to work on cheaper less powerful computers which Windows NT could not do. At first the Chicago team did not know how the final product would be sold. They thought about making two separate products MS DOS a text based system based on Windows for Workgroups . and a fully combined graphical Windows system. Before Microsoft released Windows people in the United States and United Kingdom could join the Windows Preview Program. For US . or . people received several . inch floppy disks to install Windows . They could use the disks to upgrade from Windows . or install it as a new system. They also got a free trial of The Microsoft Network MSN an online service that Microsoft launched alongside Windows . At this time Microsoft shared online documents and guides about Chicago. This included a special guide for reporters that explained the main features of the new system. These preview versions stopped working in November . After that users had to buy the final version of Windows . Microsoft got million on release day.
