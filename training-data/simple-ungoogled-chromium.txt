ungoogled chromium is a fork of Chromium that removes Google's services such as Sync. It does this by creating updates to the Chromium source code. The final browser is similar to regular Chromium. Anything that requires Google's domains such as Google Safe Browsing has been disabled. Google domains have been replaced with domains that do not exist and then those have been blocked. Allowing the user to change how the browser works using chrome flags. Some parts of regular Chromium are not the same on ungoogled chromium. For example a browser extension is required to install extensions from the Chrome Web Store. ungoogled chromium was created by a hobbyist who goes by the name Eloston in . The program was first made for the Linux operating system but then support for other operating systems was added. Eloston used to release versions of the program that were already compiled from source code but he eventually stop providing them and instead let other people provide builds with his changes. In Eloston started to get less involved with the project and other developers started to maintain his project for him. In the Github repository was given to the ungoogled software account from Eloston's own personal account.
