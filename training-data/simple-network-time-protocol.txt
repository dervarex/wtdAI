The Network Time Protocol NTP is a protocol for distributing the Coordinated Universal Time UTC by synchronizing the clocks of computer systems over IP networks. NTP is one of the oldest Internet Protocols still in use since before and uses UDP port . NTP Public Services Project This is the home for the NTP Network Time Protocol Public Services Project which provides public support for the NTP Project and the IETF NTP Working Group. Also a Wiki with lists of NTP servers.
