The Commodore shortened to C was a personal computer with KB of RAM. Commodore Business Machines released it in January and it had an bit MOS Technology CPU based on the MOS Technology and a Z A based on the Zilog Z that could run CP M software. V . The C was sold from to . It was fully compatible with the Commodore but not as popular. At the time Commodore was already developing the bit Amiga computer system. Amiga was more powerful than the C and many users preferred it. About million units were sold. The C could run in three different modes C mode Commodore mode and CP M mode. C mode allowed users to run most Commodore software without changes. Unlike the Commodore the C also included an column display mode through a second video chip.
