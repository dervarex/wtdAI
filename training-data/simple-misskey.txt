Misskey is open source software for . It was originally developed by syuilo a Japanese software engineer. When it was first developed the main service was a bulletin board but the open source community added short Notes and a timeline function. Those key features allowed the program and community to grow to its current size. A user's post is called a Note. As with other distributed social networks users can join or create servers. Each server is managed by different administrators in different locations. The origin of the Misskey name is from the lyrics of a song released by the Japanese singer . Misskey publishes its source code to GitHub. You can modify the code as long as you publish it based on AGPLv . Since Misskey also publishes you can create a personal application through the code.
