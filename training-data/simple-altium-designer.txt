Altium Designer is a computer program used to design printed circuit boards. Printed circuit boards are small boards that hold electronic parts inside computers phones and other machines. The program is made by Altium Limited an American software company. The program started in . At that time it was called Protel PCB. It was made by Nick Martin in Australia. The first version worked on MS DOS computers. In the company made a version for Microsoft Windows. New versions followed with names like Protel Protel and Protel DXP. In the program was given the name Altium Designer. In Altium Designer came out. It was the first version to use bit technology. In version added Altium which lets people work together on designs over the internet. In Altium became part of a Japanese company called Renesas Electronics. In Altium Designer was no longer sold by itself. Instead it became part of two larger products called Altium Develop and Altium Agile. Engineers use Altium Designer to draw and plan printed circuit boards. The program can show the boards in D so designers can see what they will look like before they are made. The program can be used to design many kinds of boards. These include flat boards bendable boards and boards built for harsh places like space. Altium Designer works with Octopart a search engine for electronic parts.
