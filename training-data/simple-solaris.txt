Solaris is an operating system created by Sun Microsystems in . It was created to run on their workstations but it can be used on most modern PCs and is still developed today. It used to be called SunOS until it was renamed to Solaris in . As of it is one of the main commercial UNIX variants the others are HP UX AIX and z OS . Solaris is ultimately based on UNIX System V. With version released in most parts of it were made open source and released as OpenSolaris. Solaris runs on SPARC processors as well as the bit and bit Intel and AMD processors. Oracle Corporation acquired Sun Microsystems in January . Oracle continued developing Solaris but it stopped developing OpenSolaris. OpenSolaris was later forked into the illumos kernel and the OpenIndiana distribution. It is mostly used in advanced servers like the ones that run the Internet on some workstations and for programming in languages like Java having advanced features for programmers.
