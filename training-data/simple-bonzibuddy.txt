BonziBuddy styled as BonziBUDDY was a freeware program from BONZI Software. The software was available from to . It used the Microsoft Agent technology. The program is no longer available because it contained a lot of adware malware and spyware. Most antivirus software picked up the software as Adware. The user would right click on the character. This would bring up a menu with different things that the character could do. It could tell jokes facts sing songs download files and keep people on schedule with a calendar. The user could buy add ons which would add extra jokes facts and songs. There were also game add ons and a speech recognition add on. The program itself was advertised as an Internet Companion. The official website stayed open until and then it was no longer working. BonziBUDDY can still be downloaded by uploads from fans. For the first version they used a green bird called Peedy that was created by Microsoft. In the company made their own character. They called it Bonzi. The character was a purple gorilla. When the program launched the gorilla would surf onto their screen on a yellow surf board. In later versions they changed Bonzi's entrance from a surf board to a jungle vine. BonziBUDDY had a lot of spyware. It would bring out random advertisements set the homepage to www.bonzi.com and slow down the computer. It was also rated th at PCWorld's annoying spyware products. It would also collect personal information about what people do on their computer.
