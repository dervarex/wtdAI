Windows Aero Backronym Authentic Energetic Reflective and Open is a design language used in Windows Vista and Windows . It changed the way many elements looked in the Windows interface. The Aero theme is selected by Windows automatically when the computer's hardware and software are able to run it. This includes having a video card that can handle it. If the computer does not have the hardware it needs in order to run Windows Aero Windows selects the basic theme instead. Windows Aero has animations and transparency effects. Other features enabled by Aero include enhanced taskbar previews window switching with a D effect and the ability to manipulate windows by dragging them to different parts of the screen. Some features of Windows Aero can be enabled in Windows but it was later completely removed in Windows . Third party software can be used to add the Windows Aero theme to later versions of Windows.
