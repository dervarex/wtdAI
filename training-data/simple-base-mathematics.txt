In mathematics a numeric base or radix is the number of digits that a positional system of counting uses to represent numbers. For example the most common number system used today is the decimal system. Decimal has digits to so it is a base system. A base is usually a whole number greater than but non integer bases are also mathematically possible. Binary base is used by electronic computers because they process and store information as bits binary digits which is the simplest way to represent numbers. Hexadecimal or hex base is used by many software developers because it provides a shorthand of binary at a similar scale to decimal. Hex numbers can be converted to and from binary with no math as every hex digit is exactly equal to binary digits. The oldest systems of counting used base one unary. Making marks on a wall using one mark for each item counted is an example of unary counting. Some old systems of measurement used base twelve or duodecimal.
