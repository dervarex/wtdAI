Gentoo Linux is a version of the Linux operating system. It was created by Daniel Robbins. It is named after the Gentoo penguin. Gentoo Linux uses a package management system called Portage. Portage is like the BSD ports collection. Gentoo package management is designed to be modular portable easy to maintain and optimized for the user's computer. Packages are normally built from source code continuing the tradition of the ports collection although some large software packages can be used as precompiled binaries for various architectures because it is easier. Gentoo was designed for the x architecture but also works on the x x IA PA RISC PowerPC PowerPC SPARC MIPS DEC Alpha System Z s PS Cell Processor and SuperH architectures. Official support for bit Sparc hardware has been dropped. Gentoo's official software package repository includes for example UNetbootin.
