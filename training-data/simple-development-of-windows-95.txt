In March the development of Windows began just after Windows . was released to the public and at the same time Windows NT . was still in development. Windows was later released manufacturing on July and for public in August. During initial design planning of Windows in Microsoft aimed to have the next generation high end OS and another lower end consumer designed OS as a better Windows . . The latter was to develop a bit kernel and filesystem with bit protected mode device drivers in Windows for Workgroups . to be used as the basis for the next version of Windows code named Chicago . Cairo would be Microsoft's next gen operating system based on Windows NT featuring a new UI and an object based file system but it was not planned to be shipped before . Cairo would never actually be shipped however certain elements of Cairo would show up in Windows NT . . Alongside Windows . 's release IBM started releasing OS . . Microsoft realized they needed of an updated version of Windows that could support bit applications and multitasking but could still run on low end hardware Windows NT requiring MB RAM and MB disk space did not . Initially the Chicago team did not know how the product would be packaged. Initial thoughts were there would be two products MS DOS which would just be the underlying OS an evolution of the Windows for Workgroups . kernel with a character mode OS on top and a fully graphical Windows OS. But soon into the project the idea of MS DOS was abandoned and the decision was made to develop only a fully graphical OS Windows Chicago .
