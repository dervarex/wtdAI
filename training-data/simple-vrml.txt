VRML Virtual Reality Modeling Language pronounced vermal or by its initials known before as Virtual Reality Markup Language is a standard dimensional D interactive vector graphics file format designed for the World Wide Web. It has been succeeded by X D. VRML uses text files. The vertices edges surface colors UV mapped textures shininess transparency and more of a D polygon can be specified. Graphical components can be made to fetch web pages or other VRML files from the Internet from URLs when the user clicks on the graphical component. Animations sounds lighting and other things about the virtual world can interact with the user or can happen when external events say so such as timers. A special Script Node allows program code such as program code in Java or ECMAScript to be added to a VRML file. VRML files are commonly called worlds and have the .wrl extension for example a VRML file can be called island.wrl . VRML files are in plain text and usually compress well using gzip which is useful to transfer them over the Internet faster some files compressed using gzip use the .wrz extension . Many D modeling programs can save objects and scenes in VRML format. The Web D Consortium was started to develop the format further. The International Organization for Standardization ISO have made VRML and its successor X D international standards. The first version of VRML was specified in November . It was specified from and looked a lot like the API and file format of the Open Inventor software component originally developed by SGI. The development of version . was guided by the ad hoc VRML Architecture Group VAG . A working draft was published in August . Formal collaboration between the VAG and SC of ISO began in and VRML . was submitted to ISO to be used as an international standard. The current and functionally complete version is VRML ISO IEC . X D ISO IEC has succeeded VRML. Dave Raggett created the term VRML in a paper he wrote called Extending WWW to support Platform Independent Virtual Reality which was submitted to the First World Wide Web Conference in and first discussed at the WWW VRML BOF which Tim Berners Lee started. There Mark Pesce showed the Labyrinth demo he developed with Tony Parisi and Peter Kennard. VRML was introduced to a wider audience in the SIGGRAPH Course VRML Using D to Surf the Web in August . In October at Internet World Template Graphics Software TGS demonstrated a D VRML plug in for the beta release of Netscape . by Netscape Communications. In a new version of VRML VRML also known as VRML or VRML . was finalized and became an ISO standard. VRML was used on the Internet on some personal homepages and sites such as CyberTown which used Blaxxun Software to allow D chat to be possible. SGI's Cosmo Software supported the format. When SGI restructured in the division was sold to the VREAM Division of Platinum Technology which was then taken over by Computer Associates which did not develop or distribute the software. Because of that various proprietary Web D formats came out over the next few years including Microsoft Chrome and Adobe Atmosphere neither of which is supported today. VRML's capabilities were mostly the same while realtime D graphics kept improving. The VRML Consortium changed its name to the Web D Consortium and began work on the successor to VRML which is X D. SGI ran a web site at vrml.sgi.com that hosted a string of regular short performances of a character called Floops who was a VRML character in a VRML world. A company called Protozoa created Floops. H Anim is a standard for animated Humanoids which is based around VRML and later X D. The first version of the H Anim standard . was supposed to be submitted at the end of March . VRML never saw much serious widespread use possibly because most users such as business users and personal users had low bandwidth and slow dial up Internet access. VRML was mostly experimented with in education and research where an open specification is most valued. It has now been developed into X D. The MPEG Interactive Profile ISO IEC was based on VRML now on X D and X D is largely backwards compatible with it. VRML is also widely used as a file format to distribute D models mostly from CAD systems. A free version of VRML for multiple platforms called OpenVRML is available. Its libraries can be used to add both VRML and X D support to applications and a GTK plugin that allows VRML X D worlds to be rendered in web browsers is available. In the s many companies such as Bitmanagement improved the quality level of virtual effects in VRML to the quality level of DirectX . c using proprietary solutions. All main features like game modeling are already complete. They include multi pass render with low level setting for Z buffer BlendOp AlphaOp Stencil Multi texture Shader with HLSL and GLSL support realtime Render To Texture Multi Render Target MRT and PostProcessing. Many demos show VRML supports lightmap normalmap SSAO CSM and Realtime Environment Reflection and other virtual effects.
