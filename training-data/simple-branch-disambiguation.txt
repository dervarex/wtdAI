Branch computer science a point in a computer program where program flow may change depending on a condition. Branch predictor the part of a processor that determines whether a conditional branch in the instruction flow of a program is likely to be taken or not. Branch table a term used to describe an efficient method of transferring program control branching to another part of a program using a table of branch instructions. Indirect branch a type of program control instruction. Branching software a way of duplicating an object under revision control.
