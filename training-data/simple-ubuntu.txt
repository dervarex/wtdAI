Ubuntu is a free operating system that uses the Linux kernel. It is named after the word ubuntu which is a Zulu word meaning humanity to others . It is pronounced oo boon too . Ubuntu is one of the most popular Linux distributions. It is based on the Debian Linux computer operating system. Ubuntu can be used on all types of personal computers and even devices such as robots including in Windows . Ubuntu is downloaded as a DVD's ISO image which is free to download from the Ubuntu website. It can be installed or tested by running the DVD. A new release of Ubuntu is released every six months. The long term support releases are one type of these and they are released every two years. Due to their longer periods of update support most users prefer to install those releases. They are Free software here includes only software that meets the Ubuntu licensing requirements which almost are the same as the Debian Free Software Guidelines. There is one difference for the Main category however it has firmware and fonts which cannot be changed but are included if Ubuntu will not work right. Non free software is usually unsupported Multiverse but some exceptions Restricted are given for very important non free software. Supported non free software include device drivers that are needed to run Ubuntu on current hardware. The level of support in the Restricted category is less than that of Main since the developers may not be able to get to the source code. It is wanted that Main and Restricted should contain all the software needed for a general use Linux system. Besides the official repositories is Ubuntu Backports which is an officially known project to backport newer software from later releases of Ubuntu. The repository is not comprehensive meaning that it has parts missing from it it is mostly made up of user requested packages which are accepted if they meet quality guidelines. Ubuntu not only uses traditional Debian packages DEB and Personal Package Archives PPAs but also Snap packages. Since Ubuntu has support Snaps. Snaps are similar to Flatpaks. It is a package format developed by Canonical that bundle applications together with their dependencies and run in isolated environments known as sandboxes. Canonical states that this approach simplifies software distribution improves security and allows developers to provide the same experience across multiple Linux distributions. Several applications in Ubuntu including some installed by default are distributed as Snap packages. However Snaps have faced some criticism. Quantal Quetzal search results from the desktop launcher could include product suggestions from Amazon. When users searched for files or applications on their computers some search terms were sent to Canonical's servers to retrieve online results. The feature attracted criticism from privacy advoates and some Ubuntu users who argued that desktop searches should not send information over the internet by default. Richard Stallman founder of GNU a collection of free software that is used a lot in Linux and Ubuntu said that the Amazon integration is spyware . Canonical stated that the feature was intended to provide useful shopping results and could be disabled. More specifically Mark Shuttleworth the founder of Canonical pushed back saying that the data being sent is anonymous and does not contain identifiable information. The company later removed the Amazon integration from Ubuntu. Some users and developers have criticized Snap packages for slower startup times large storage requirements because it bundles dependencies with every application and integration issues compared with traditional package formats. Others have also expressed concern about Canonical's central control of the Snap Store. Because there is only one Snap Store arguing that it reduces the level of decentralization there are many software repositories for Debian for example traditionally associated with Linux software distribution. Moreover if you tried to install some software using APT e.g. chromium browser it would instead install the Snap version instead instead of the expected traditional DEB package. In the early s Ubuntu displayed promotional messages in the command line terminal for some users. These messages often promoted Ubuntu Pro Canonical's subscription service that provides additional security updates and support. Some users viewed the messages as advertisements appearing in a tool that is commonly used for system administration and development. Critics argued that such notices were intrusive while Canonical described them as informational messages about available services.
