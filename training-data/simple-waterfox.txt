Waterfox is a free and open source browser based on Firefox. It was designed for bit systems back when Firefox was only for bit. Now the main features of Waterfox are based on speed and privacy. Waterfox Current is almost the same as Firefox. They both use Gecko and SpiderMonkey to show websites. It also works with Firefox Chrome and Opera extensions. It turns off telemetry data collection and Pocket web service . But it collects details about the user's device to send the right updates new changes to the user's browser. Waterfox Classic is a copy of the browser that uses the older copy of Gecko that still works with XUL and XPCOM add ons. These add ons do not work anymore on copies after Firefox . The browser can also be easily seen as similar to Firefox showing the default Australis theme. It is still being kept up with the security changes from Waterfox Current and Firefox ESR. But it has some security problems that are not fixed yet. This is because some new changes would not work on it. On March Waterfox was first posted and distributed given by Alex Kontos for bit Windows. The copy for Mac was posted on May after version . was posted. The copy for Linux was posted on December after version . was posted. From July to November Waterfox had its search engine called Storm based on Yahoo Search. It was made with investor funding and it raised money for Waterfox and charity giving money to the needy . In December System an advertising paid notice company that claims to be focused on privacy bought Waterfox. In July Alex Kontos said that Waterfox is an independent and separate project again. In December Waterfox auto update v . . was released along with the announcement that the official web site has migrated from Waterfox.net to Waterfox.com.
