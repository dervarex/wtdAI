Nintendo DS system software is software on the Nintendo DS video game console that can be updated. These updates which are downloaded through the system's Internet connection lets Nintendo add and take away features and software. Updates also have changes from previous versions. The newest version of the system software . . was released on December . The Home Menu is a GUI like the Wii's Wii Menu and the DSi's DSi Menu which lets you use applications from Nintendo game cards DS applications or DSiWare applications. The menu has space to show applications though spaces for one application each will show when space starts to run out. On the top screen the menu shows information such as signal strength step count date time and battery life. With the home button the user can go to the HOME menu except for DS games or DSiWare which won't let the player go there without quitting the game. From the home screen the user can manage notes check friend lists change the level of light check notifications and if updated to the latest version browse the internet all without closing the current application. At the home menu the user can also take photos with the D cameras by pressing the L or R buttons. To open another application the one the player is using must be closed first. Like the DSi game cards can be swapped while in the menu.
