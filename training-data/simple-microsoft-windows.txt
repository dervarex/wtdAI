Microsoft Windows is an operating system for computers made by the United States based company Microsoft. Windows is the most popular operating system being used by almost of desktop and laptop computers. Versions are available all over the world especially in the European Union United States Canada Australia and the United Kingdom. The first version of Windows Windows . came out on November . The newest version Windows came out October . Most personal computers made after come with Windows . However some older or cheaper personal computers may come with Windows . or Windows . Windows makes it easier to run programs also called applications than MS DOS did. DOS required typed commands to make the computer do something. However DOS required correct syntax of each command. Making mistakes caused the computer to usually give an error message and do nothing. In July Microsoft announced it would start giving out subscriptions to virtualized Windows desktops as part of a new Windows service in the following month. The service allows cross platform usage aiming to make the operating system available for both Apple and Android users. It is a separate service and offers several editions including Windows Frontline Windows Boot and the Windows app. The subscription service is accessible through any operating system with a web browser. The service is Microsoft's attempt at capitalizing on the growing trend fostered during the COVID pandemic for businesses to adopt a hybrid remote work environment in which employees split their time between the office and home. As the service is accessible through web browsers Microsoft is able to bypass the need to publish the service through Google Play or the Apple App Store. Microsoft announced the availability of Windows to the business and enterprise customers on August . Users control their Windows computer by its graphical user interface GUI . It only needs a keyboard or a mouse to work. In later versions a touch screen works as well. However using both a keyboard and a mouse makes many tasks easier. By clicking a few buttons on the screen Windows helps keep your files safe and easier to change and move. Versions of Windows after make it even easier for some users with disabilities because these versions have touch screens. Tablet computers such as Microsoft Surface use Windows. The following programs are included with Windows Notepad to write simple documents typically using words text. Photos to view and edit pictures. Paint to make simple drawings or change pictures. Microsoft Edge to use the Internet to look at web pages and download files. Windows Media Player to play music videos and DVD's. Windows has several kinds of applications available. Popular applications include games word processors or additional programs like Eudora. Adding new applications to Windows is called installing . Applications can be bought or purchased on a CD or DVD. Applications can also be downloaded from the Internet. Some internet applications can be downloaded for free and others can be bought using the internet. Many users complain that Windows makes problems for them. Some users complain that Windows made their computers slower when they changed from DOS. Many people also complain about problems that make their computer less safe to use even though Microsoft tries to fix these problems. Many computer viruses are made to infect computers running Windows since it is such a popular operating system. Windows was the most popular operating system until recently today mobile operating systems such as Android are more popular .
