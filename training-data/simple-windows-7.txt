Windows is a no longer supported version of Microsoft Windows an operating system for personal computers. It is the successor to Windows Vista the sixth major release of the Windows operating system. According to Microsoft Windows improves the speed reliability and compatibility from Windows Vista. Windows was once the most popular Windows version by far but is by now third most popular with a tiny market share. The beta version of Windows was released on January and the release candidate was released on May . The final version of Windows was sent to PC manufacturers on July so that they have three months to change it and include it with their computers. Windows was released to the public on October . On January Microsoft Internet Games Services stopped working on Windows . Extended Security Updates ESU is a paid computer program which allowed to receive security updates for some Microsoft products for years after the end of extended support date which is now in the past excluding for some embedded editions and for Azure customers of its server counterpart Windows Server R . Windows includes many new features such as touchscreen supporting virtual hard disks being faster on multi core processors and a redesigned taskbar. The taskbar allows users to pin the most frequently used programs directly to it instead of on a toolbar. The glass user interface Aero has been improved with features such as Aero Shake Aero Snap and Aero Peek. Windows has removed some features that were in Windows Vista including Windows Mail Windows Movie Maker Windows Photo Gallery Windows Calendar Windows Ultimate Extras and the InkBall game as well as many customization options such as the Classic Start Menu. Windows Mail Windows Movie Maker and Windows Photo Gallery were replaced by similar set of programs known as Windows Live Essentials. The Windows Live Essentials are not included in Windows and have to be downloaded from Microsoft's website. Features planned for Blackcomb included the Sidebar an emphasis on looking for data and an advanced storage system named WinFS. However a minor release code named Longhorn was announced for delaying the making of Blackcomb. By the middle of Longhorn had gotten some of the features meant for Blackcomb. After three major viruses exploited flaws in Windows operating systems within a short time in Microsoft changed its development priorities putting some of Longhorn's major development work on hold while they made new service packs for Windows XP and Windows Server . Development of Longhorn was reset in September and it was renamed to Windows Vista in July . A number of features were cut from Windows Vista as it was being remade. Blackcomb was renamed to Vienna in January and was later scrapped in due to the scope of the project.
