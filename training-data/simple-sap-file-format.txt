SAP is a way to store music data from the Atari bit family that uses the POKEY sound chip. Most popular music for the Atari bit family was written between and . SAP files are similar to SID Commodore SPC Super Nintendo Entertainment System and NSF Nintendo Entertainment System files because players emulate the CPU and sound hardware of the system to play music. SAP files can be played by a SAP player which many platforms have. For example VLC version and higher can play SAP files on Apple Macintosh computers using the PowerPC and Intel architectures.
