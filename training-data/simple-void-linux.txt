Void Linux is a Linux distribution that uses the XBPS package manager to install software instead of the more commonly used APT and DNF. This also means it is an independent Linux distribution most Linux distributions are based on other distributions such as Debian or Ubuntu but Void Linux is built from scratch. It uses the runit init system instead of systemd. This can cause compatability issues with some software especially the GNOME and KDE desktop environments. Besides non free kernel blobs a normal install is free software only. Users can still get things from an official non free software repository if they like. Void Linux is different from most Linux distributions. It uses runit instead of systemd as the init system. The init system handles the background services on a Unix like OS and is important to the boot process. It also supports musl instead of glibc which is a form of the C standard library libc that is more lightweight. As of May Void Linux now provides Flatpak. Flatpak is a package management utility which lets users install a wider range of software.
