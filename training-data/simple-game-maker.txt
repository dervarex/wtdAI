Game Maker is a computer program for the Windows operating system. It was first made by Mark Overmars but it is now made by the company YoYo Games. Game Maker lets people make computer games without knowing a computer programming language. People who know how to use programming languages can use Game Maker's own programming language called Game Maker Language. The newest version is Game Maker Studio. Since the first version made in Game Maker was given many new features. One of these features is D graphics. Game Maker has a drag and drop interface. This lets people make games using mostly the computer mouse. Game Maker uses icons that tell the person what actions they can do. People can make simple games by moving these icons into a given order. More detailed games can be made when Game Maker Language is used. Game Maker has an internet community and website. There people who use Game Maker can put their games up for others to play. People can also get help on using Game Maker from other people. Game Maker started as an animation program called Animo.
