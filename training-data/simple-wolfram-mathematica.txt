Wolfram Mathematica usually called Mathematica is a modern technical computing system made by Wolfram Research. Today Wolfram Mathematica is used for the following purposes Computer science Data science Deep learning Geometry Interval arithmetic Machine learning Numerical analysis Numerical linear algebra Numerical methods for ordinary differential equations Numerical methods for partial differential equations Neural network Optimization This system is made with the Wolfram Language programming language named after Stephen Wolfram .
