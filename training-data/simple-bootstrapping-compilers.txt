Bootstrapping is a computer science method to create a programming language that is compiled with itself. In most cases a compiler is written in a language where the compiler is rewritten for the language that is being compiled. Most popular programming languages all follow a pattern of bootstrapped compilers. Some notable ones include C C D Java Pascal Python Rust V Vlang and more. Bootstrapping usually has just a few stages Build prepare tools and software to create a bootstrap compiler. Stage Create a compiler for your programming language using another language or whatever tools you have. This will be used to compile your final compilers. Stage Use your created compiler to recreate your original compiler. This should be identical to a stage compiler. Stage Any newly added features would be added at stage where the language is now only written in itself and is compiled using a compiler compiled in the same language. In Tim Hart and Mike Levin wrote a compiler for LISP inside of LISP. They improved the compiler until it was capable of compiling itself.
