Windows Server is a no longer supported server operating system from Microsoft the previous version of which was Windows Server . This operating system was codenamed named Windows Server Longhorn but on May Bill Gates announced its official name on Windows Hardware Engineering Conference . This operating system has several new features compared to its previous version. Many of these new features are present in Windows Vista. Windows Server removed support for processors without ACPI. It is the first version of Windows Server that includes Hyper V and is also the final version of Windows Server that supports x based processors also know as IA based or bit processors . Its successor Windows Server R requires a bit processor in any supported architecture x for x and Itanium .
