Unicheck previously known as Unplag is a cloud based plagiarism checking software. It finds similar text and can also detect citations and references in documents. Unicheck is used in K and higher education. It can also be used by individual users such as writers editors bloggers and lawyers. Unicheck was made by IT company Phase One Karma and launched in under the name Unplag. In Unicheck partnered with the X ulture project and became a Certified Partner with the Canvas learning management system by Instructure. In it gained a status of Canvas Alliance Partner. In Unicheck added an integration with Google Classroom. It later added a native Canvas integration that uses LTI and API. In January Unicheck released an add on for Google Docs. In Unicheck made by Phase One Karma was acquired by Turnitin. Unicheck continued to operate as a separate service. Unicheck checks text and shows where similar text is found. The results are shown in a similarity report. Each match includes a link to the source. Reports can be downloaded as PDF files. Unicheck can be used as a stand alone tool. It can also be connected to a learning management system LMS using a plug in LTI an API or both. Unicheck can check many file formats including .doc .docx .rtf .txt .odt .ppt .pptx .html .pdf and files from Google Drive OneDrive and Dropbox. Users can also store documents in an internal library and choose whether checked documents are shared with Unicheck's database. Unicheck uses an algorithm to search for similar text on web pages in open source repositories and in a user's internal library. Some papers describe parts of its approach including methods used for authorship attribution and paraphrase detection. Unicheck can also identify properly formatted citations and references in common styles such as APA MLA and Chicago.
