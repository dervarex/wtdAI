Elementary OS officially styled as elementary OS is a Linux distribution. It is based on Ubuntu LTS. Its goal is thoughtful capable and ethical computing . The operating system uses the Pantheon desktop environment. It is developed by elementary Inc. The design philosophy of elementary OS is very similar to macOS visually and in user experience.However the elementary developers say that they have a lot of differences. The human interface guidelines of elementary OS say that it should instantly be clear how to use a program. The three core rules that the developers set for themselves were concision shortness accessible configuration and minimal documentation. The Pantheon desktop environment uses a lot of code from GNOME most noticeably GTK. The desktop has multiple workspaces to organize windows. It has a menu bar and a dock similar to macOS. elementary OS were originally GNOME themes and later became its own Linux distribution.
