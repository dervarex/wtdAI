In cryptography RC is a symmetric key block cipher. Designed by Ronald Rivest in . RC stands for Rivest Cipher or alternatively Ron's Code . RC is a bit block cipher with a variable key size and using rounds. Rounds are arranged as a source heavy feistel network with rounds of one type called mixing rounds interleaved by two rounds of another type called mashing rounds . The rounds are performed using the following interleaved sequence perform mixing rounds. perform mashing round. perform mixing rounds. perform mashing round. perform mixing rounds. RC uses key expansion algorithm by which an expanded key consisting of bit words is produces depending in a complicated way on every bit of the supplied variable length input key. RC is susceptible to a related key attack using chosen plaintext attacks Kelsey et al. . The development of RC was sponsored by Lotus who were seeking a custom cipher be exported as part of their Lotus Notes software after evaluation by the NSA. The NSA suggested a couple of changes which Ronald Rivest incorporated. After further negotiations the cipher was approved for export in . Along with RC RC with a bit key size was treated under US export regulations for cryptography. Now all bit encryption algorithms are obsolete because they are dangerously susceptible to brute force attacks. Initially the details of the algorithm were kept secret proprietary to RSA Security but on January source code for RC was anonymously posted to the Internet on the Usenet forum sci.crypt. A similar post had occurred earlier with RC . It is unclear whether the poster had access to the specifications or whether it had been reverse engineered.
