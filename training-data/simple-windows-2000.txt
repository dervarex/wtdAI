Windows also known as Win K W K Win or Windows K is an operating system for computers that have either single or multiple processors. It was made for bit Intel x computers. It is part of the Microsoft Windows NT line of operating systems and was released on February . Windows comes in four versions Professional Server Advanced Server and Datacenter Server. Additionally Microsoft offers Windows Advanced Server Limited Edition and Datacenter Server Limited Edition which were released in and run on bit Intel Itanium processors. Windows was designed for businesses but it was also popular with home users. Windows uses two 'modes' a 'User Mode' and a 'Kernel Mode'. The Kernel Mode is specially for hardware drivers drivers tell the computer how to 'speak' to something and allows drivers to 'speak' to things in the computer. The User Mode is for computer programs to run in without fear of causing harm to the computer. All versions of Windows have things in common including many system utilities such as the Microsoft Management Console MMC and standard system management applications such as a disk defragmentation utility. There is lots of support for different languages and for people with disabilities. Windows supports the Windows NT file system NTFS the Encrypted File System EFS as well as basic and dynamic disk storage. Dynamic disk storage allows different types of volumes to be used a volume is an area of storage on a hard disk that has been formatted with its own file system structure . The Windows Server version has many more features including the ability to provide Active Directory services a way of organising resources such as printers users and group a distributed file system a file system that supports sharing of files and fault redundant storage volumes. Windows can be installed and deployed to an enterprise through either an attended or unattended installation. Unattended installations rely on the use of answer files to fill in installation information and can be performed through a bootable CD using Microsoft Systems Management Server SMS by the System Preparation Tool Sysprep . Windows was created from the Microsoft Windows NT operating system versions. It was originally called Windows NT . but Microsoft changed the name to Windows on October . The first software test version also known as a beta version for Windows was released on September . Several more test versions were released until Beta which was released on April . Microsoft further issued three more test versions from between July to November . They then finally released Windows to partners on December . The public received the full version of Windows on February and the press immediately called it the most stable operating system Microsoft had ever released. Novell a competitor of Microsoft did not think that Microsoft's new directory service product part of Windows was as good as their own Novell Directory Services NDS technology . On September Microsoft released Windows Datacenter. Microsoft released Service Pack SP on August Service Pack SP on May Service Pack SP on August and its last Service Pack SP on June . Microsoft has said that they will not release a Service Pack but instead have offered an Update Rollup for Service Pack . Microsoft stopped developing their Java Virtual Machine JVM for Windows in Service Pack . Microsoft replaced Windows Professional with Windows XP Professional and Windows Server products with Windows Server . A project code named Neptune started development in . Neptune was based on Windows and it was supposed to be a home user replacement for Windows . However the project took a long time to create and only one pre test alpha version release was created. Windows Me was released instead and the Neptune project later turned into part of a project that became Windows XP. The only elements of the Neptune project which were included in Windows were the ability to upgrade from Windows or Windows and support for the FAT file system. Several notable security flaws have been found in Windows . Code Red and Code Red II were famous computer worms that used problems with the indexing service from Windows 's Internet Information Services IIS to cause security problems. In August two major worms named the Sobig worm and the Blaster worm began to attack millions of Microsoft Windows computers and caused many problems for system administrators and computer operators who used Windows . This was very embarrassing for Microsoft and caused many corporations and governments to look carefully at Microsoft's security problems.
