Panda Cloud Antivirus is a cloud based antivirus program made by Panda Security. It was one of the first antivirus programs to use cloud technology for virus detection. A free version and a paid version are available. Panda Cloud Antivirus scans files on remote servers instead of using the computer's own processing power. This helps keep the software lightweight and always up to date. The system is powered by Panda's Collective Intelligence platform which collects and analyzes new malware samples from users around the world in real time. Panda Cloud Antivirus protects against viruses worms trojans spyware hacking tools and other types of security risks. It usually needs an Internet connection to access updated threat information. If offline it uses a local cache with the most common threats. An early review described Panda Cloud Antivirus as clean simple and fast with good malware detection rates. When version . was released in November PC Magazine awarded it Editor's Choice for best free antivirus software. TechRadar wrote that Panda Cloud Antivirus is best as a defense tool rather than a cleanup utility. In Softpedia noted that virus removal was slow in version . but said it was good for normal Internet users who avoid unsafe websites. The free edition of Panda Cloud Antivirus is only allowed for personal use schools and non profit organizations.
