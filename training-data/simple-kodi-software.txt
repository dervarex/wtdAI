Kodi originally called XBMC is a open source media center made by the Kodi Foundation a nonprofit organization. The software is available for many different operating systems with a menu made for televisions. The software allows users to get media such as videos and music from the Internet and allows users to load media from external media such as a USB flash drive or DVD. It was originally made as a home theater PC application that could run on many different types of computers but now has become a multi purpose program that can run plug ins which are similar to applications similarly to a operating system. The media player can have its look changed using skins and allow users to watch content from streaming services such as Netflix and Hulu using plug ins. Kodi claims to officially support any computer made in the last years with the minimum requirements on their official website.
