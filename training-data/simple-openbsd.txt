OpenBSD is a secure free computer operating system. Many different types of hardware platforms and CPU microarchitectures can be used with OpenBSD including AMD amd Intel i bit ARM PCs and servers bit ARM embedded systems Apple Computer and IBM PowerPC bit RISC V and Sun and Fujitsu bit SPARC . Like the other open source BSDs the whole operating system Kernel computer science Device driver user Utility software and Documentation is developed by the OpenBSD project's developers. Software from other third party source is available separately via binary packages or source code ports. OpenBSD is often the first to add new security tools to make it harder to break. Developers have also carefully read through the programming code to check for mistakes more than once. The project is led by Theo de Raadt from Calgary Alberta Canada. There are few restrictions on people that use the source code the BSD licence. OpenBSD releases new versions every six months. Each version is supported for one year after release. OpenBSD . the th release was made available on th May . OpenBSD's first mascot was a BSD daemon with a halo it was replaced with Puffy a pufferfish on June th with the release of OpenBSD . . The operating system's developers add in many new technologies to make the system more secure and harder to break technologies like W X Stack Protection randomised malloc reconfigurations privilege separation and privilege revocation syscall capability reduction via pledge and per process filesystem views with unveil . In addition to the OpenBSD operating system the OpenBSD Project's associated projects produce security software commonly used in many operating systems the most widely used derivative of SSH OpenSSH is utilised by not only other BSD systems but macOS Microsoft Windows and the majority of GNU Linux distributions and embedded in many networking devices LibreSSL a fork of OpenSSL . . g as a repsonse to the Heartbleed Software bug of provides a modern cryptography and TLS stack default or selectable for other BSDs commercial UNIX macOS GNU Linux and Microsoft Windows see the LibreSSL for a discussion of platform coverage and relationship with other SSL implementations. OpenBGPD which provides diversity in Border Gateway Protocol Version implementation at the routing level of the internet it is utilised by many internet exchange operators around the world. Because of its security features OpenBSD is often used as a firewall and for other security related jobs. It is also usable on a desktop computer.
