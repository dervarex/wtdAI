Windows is an operating system for computers. Released on June by Microsoft it is the successor of Windows . It came before Windows Me. Support for Windows ended on July . Windows was seen by many as a small upgrade to Windows rather than a rebuilt version of Windows. The biggest changes were Internet Explorer a web browser was made part of the GUI what the user sees and the file manager. This had already happened in the last versions of Windows that were released. This is called 'web integration'. Larger disk partitions separations were allowed. New tools were added to help make the computer run the way a user wants it to. System Configuration Utility is a tool that lets users turn off programs they do not need to use the computer. Disk Cleanup let users delete old files the computer made. Some add ons that were made for Windows were included with Windows such as the changes to the shell from Microsoft Plus for Windows . Because Microsoft made Internet Explorer such an important part of Windows the company was taken to court by the United States government. This was because they felt it was unfair to other companies who made web browsers. It is not supported anymore but many people still use it on older computers that will not run Windows XP or later versions of Windows. Before the release of Windows there was a press demonstration at Comdex in April . Microsoft CEO Bill Gates was highlighting the operating system's ease of use and enhanced support for Plug and Play PnP . When presentation assistant Chris Capossela plugged a scanner in and attempted to install it Windows displayed a Blue Screen of Death. Gates remarked after applause and cheering from the audience That must be why we're not shipping Windows yet. Video footage of this event became a popular Internet phenomenon. Windows Second Edition SE was released in . This was an official upgrade to Windows which allowed people to use more types of computer hardware like monitors and printers and also let more than one machine on a network use the same Internet connection.
