Python is an open source programming language. It was made as a language that is both easy to work on and understand. It was made by a Dutch programmer named Guido van Rossum in who named it after the television program Monty Python's Flying Circus. Python is an interpreted language. This means it does not need to be compiled before running. A program called an interpreter runs Python code on almost any computer. This makes Python slower than compiled languages like C because it is not changed into machine code before running. But this also allows the programmer to change the code and quickly see what happens. Python is a general purpose programming language. It can be used for many purposes. Python is often used for making websites automating common tasks and making charts and graphs. Since it's simple to learn people who are not computer experts like bookkeepers and researchers often learn Python. Python's standard library is made up of many functions that come with Python when it is installed. On the Internet there are many other libraries which do tasks in varied areas like Machine Learning ML Deep Learning etc. When speed is important a Python programmer can write some of the program in a different language like C or use PyPy a different kind of Python that uses a just in time compiler. Keeping Python fun to use is an important goal of Python's developers. It reflects in the language's name a tribute to the British comedy group Monty Python. Tutorials often take a playful approach such as referring to spam and eggs instead of the standard foo and bar. Python uses whitespace to separate code spaces or tabs are used to organize code into groups. This is different from C. Python's statements include the following keywords The if statement runs its first block of code if its condition is met. The optional elif a contraction of else if statement runs its block of code if the previous conditions are not met but its condition is met. The else statement runs the last block of code if none of the previous conditions are met. The while statement is a loop. As long as its condition is met it runs its block of code. The for statement is a loop with an index. It iterates over a list and binds each element to the index to use in that block. The def statement defines a function or method. The pass statement does nothing. The class statement allows the users to create their own type of objects like what integers and strings are. The import statement imports Python files for use in the user's code. The print statement outputs a message to the console. Python's expressions include some operators that are similar to other programming languages and others that are not Addition subtraction multiplication and division . Exponents represented by . To compare two values the condition uses . Python uses the words and or and not for its boolean expressions. To check if a value is in a list Python uses in.
