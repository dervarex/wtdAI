Rust is a programming language designed for systems which are software designed to provide a platform for other software . It is or was used to write operating system and web browser components services such as OpenDNS and Tor and game engines. It was made by former Mozilla engineer Graydon Hoare. Software developer Graydon Hoare created Rust as a personal project while working at Mozilla Research in . Mozilla officially sponsored the project in .
