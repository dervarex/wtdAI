x is a term used to describe a CPU instruction set compatible with the Intel and its successors including the Pentium and others made by Intel and other companies. This is the CPU architecture used in most desktop and laptop computers. Many st century workstations and servers also use x processors. In the original bit x architecture was extended to bits with the introduction of the i processor. It was extended again to bits in with the introduction of the AMD Opteron processor. Intel adopted the bit computing bit architecture in with the later versions of the Prescott Pentium . The different versions are backward compatible meaning that a bit x CPU can run a bit or bit operating system and a bit x CPU can run a or bit operating system. All x CPUs with the rare exception of some Intel CPUs used in embedded systems start in bit real mode.
