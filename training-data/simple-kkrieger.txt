.kkrieger from Krieger the German word for warrior is a first person shooter video game created by the German demogroup .theprodukkt formerly part of Farbrausch . The game won first place in the k game competition at Breakpoint in April and is in the beta stage. The game has been in development since mid using .werkkzeug an unreleased version of .werkkzeug from Werkzeug the German word for tool . The source code of .werkkzeug was released in . It can be used under the BSD license or placed in the public domain. Textures in the game are very small and are generated using creation history instead of storing single pixels. Basic shapes such as boxes and cylinders are modeled into more complex shapes. Loading these generated elements at the same time can take a long time. At the time most popular first person shooter games required one or more CDs or DVDs but .kkrieger uses only bytes. This is over times smaller than a CD MB and about times smaller than an Unreal Tournament installation . GB . That game normally shipped on a DVD. The developers of .kkrieger estimate that storing the game in a normal format would require about MB. The V synthesizer streams the game's music and sound effects using MIDI. The game won two awards at the Deutscher Entwicklerpreis in Innovation and Advancement. Gaming website Acid Play gave the game out of stars and published a mixed review noting that the game was buggy but praising how much content was stored in such a small file size.
